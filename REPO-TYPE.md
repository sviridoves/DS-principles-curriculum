# Тип репозитория

**Тип**: `DS/surface`
**Система (SoI)**: Учебные программы по принципам мышления
**Содержание**: text-surface (программы, ячейки, курсы)
**Для кого**: personal
**Source-of-truth**: no

## Upstream dependencies

- PACK-MIM (MIM) — методика обучения
- ZP (нулевые принципы)
- FPF (первые принципы)

## Downstream outputs

- Готовые программы обучения принципам мышления (потребляются участниками)

## Non-goals

- Хранение предметных/доменных знаний (→ Pack)
- Формулировки самих принципов (→ ZP/FPF)
- Планы/отчёты (→ DS-strategy)
